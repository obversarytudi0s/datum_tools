# Data Engineering Toolbox

A collection of modular Python scripts for common data engineering tasks.

## Structure
- `connectors/`: Scripts for interacting with APIs, Databases, and Cloud Storage.
- `processing/`: Data cleaning, transformation, and aggregation utilities.
- `validation/`: Schema checks, data quality tests, and sanity checks.
- `utils/`: General helpers (logging, config loading, date handling).
- `pipelines/`: Example orchestrations combining the above modules.
